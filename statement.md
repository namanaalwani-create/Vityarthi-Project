Personal Expense Tracker

1. Problem Statement

Calculating and managing daily expenses on a paper is difficult. It can be hard to remember where money was spent and how much was spent.

The Personal Expense Tracker is a Python program that helps users record and manage their daily expenses. It can add, view, search, update, and delete the expenses.

2. Scope of the Project

The project is made for managing basic personal expenses.

It can be used to:

Record daily expenses
View saved expenses
Search expenses by category
Update expense details
Delete expenses
Find the total amount spent

3. Target Users

This project is mainly for:

Students
Beginners
People who want to keep track of daily expenses
Who want a simple expense management program

4. High-Level Features

Add Expense: Add the date, category, and amount.
View Expenses: See all recorded expenses.
Search Expense: Find an expense by its category.
Update Expense: Change the details of an expense.
Delete Expense: Remove an expense.
Total Expense: Calculate the total amount spent.
